# Industrial Equipment Health Monitor

A Streamlit academic prototype for machine health monitoring and predictive maintenance.

## Run locally

1. Install Python 3.10–3.12.
2. Open a terminal in this folder.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the website:

   `streamlit run app.py`

## Deploy

Push `app.py` and `requirements.txt` to a GitHub repository, then create an app at https://share.streamlit.io/ using `app.py` as the main file.

## Important note

This prototype trains on synthetic demonstration data generated in the code. Its test accuracy is not evidence of real industrial performance. Do not use it for operational safety decisions.
